# 네이버 언론사 뉴스 자동 수집기

네이버 언론사 페이지와 기사 상세 페이지를 일반 HTTP 요청으로 조회해, 실행일의 한국어 기사만 날짜별 CSV로 저장하는 Node.js 프로젝트입니다. Selenium이나 유료 API는 사용하지 않습니다.

## 수집 대상

| 언론사 | 네이버 press ID |
|---|---:|
| SBS | `055` |
| 한국경제 | `015` |
| 매일경제 | `009` |

각 언론사의 정치, 경제, 사회, 생활/문화, 세계, IT/과학 섹션을 확인합니다. 같은 기사가 여러 섹션에 있으면 `정치|경제|사회`처럼 정해진 순서로 합칩니다. 제목에 한글이 한 글자도 없는 기사는 제외합니다.

기사 목록의 상대시간은 사용하지 않습니다. 각 기사 상세 페이지의 실제 발행시각을 확인해 `Asia/Seoul` 기준 실행일과 같은 기사만 `YYYY-MM-DD HH:mm` 형식으로 저장합니다.

## 자동 실행

GitHub Actions는 `Asia/Seoul` 기준 매일 오전 9시에 실행됩니다. GitHub가 지원하는 IANA 시간대 설정을 명시했기 때문에 UTC로 직접 환산할 필요가 없습니다.

실행 시간을 바꾸려면 [`.github/workflows/daily-news.yml`](.github/workflows/daily-news.yml)의 다음 `cron` 한 줄만 수정합니다.

```yaml
- cron: '0 9 * * *'
```

예를 들어 매일 오전 7시 30분으로 바꾸려면 `'30 7 * * *'`로 수정합니다. 예약 workflow는 기본 브랜치에 있어야 실행됩니다.

### 수동 실행

1. GitHub 저장소의 **Actions** 탭을 엽니다.
2. 왼쪽에서 **Daily Naver News**를 선택합니다.
3. **Run workflow**를 눌러 실행합니다.

CSV가 바뀐 경우에만 기본 `GITHUB_TOKEN`으로 자동 커밋·푸시합니다. 내용이 같으면 커밋하지 않습니다.

## 결과

결과는 `data/YYYY-MM-DD.csv`에 저장됩니다.

```text
언론사,섹션,발행시각,제목,URL
매일경제,경제,2026-08-19 09:43,코스피 장 초반...,https://n.news.naver.com/article/009/0005722679
```

CSV 컬럼 순서는 `언론사, 섹션, 발행시각, 제목, URL`이며 최신 발행시각부터 정렬합니다. Excel에서 한국어가 깨지지 않도록 UTF-8 BOM을 사용합니다. 같은 날짜에 다시 실행하면 그 날짜의 파일을 최신 수집 결과로 덮어씁니다.

## 로컬 실행

Node.js 20.18.1 이상이 필요합니다.

```bash
npm ci
npm test
npm run crawl
```

실행 로그에는 언론사별 목록 기사 수, 영문 제목 제거 수, 중복 제거 전후 수, 발행시각 확보 성공/실패 수, 최종 저장 수와 실패 섹션이 표시됩니다. 일부 언론사나 섹션 요청이 실패해도 나머지는 계속 처리합니다. 요청한 섹션을 언론사가 제공하지 않아 네이버가 홈 탭으로 되돌린 경우에도 잘못된 섹션으로 저장하지 않고 실패 섹션으로 기록합니다. 모든 언론사의 모든 섹션이 실패하거나 최종 결과가 0건이면 비정상으로 보고 종료 코드 1을 반환합니다.

## 네이버 HTML 구조가 바뀐 경우

링크와 발행시각 선택자, URL 정규화 로직은 [`src/crawl.js`](src/crawl.js)에 있습니다. 수집 결과가 갑자기 0건이 되거나 발행시각 실패가 급증하면 다음 부분을 확인합니다.

- `parseSectionPage()`: 언론사 섹션 페이지의 기사 링크와 제목 선택자
- `parseArticlePage()`: 기사 상세 페이지의 실제 발행시각과 제목 선택자
- `normalizeArticleUrl()`: 네이버 기사 URL 형식

파서의 기본 동작은 [`test/crawl.test.js`](test/crawl.test.js)에서 확인할 수 있습니다.
